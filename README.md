My smaller projects and experiments. Each has an MP4 demo clip inside the folder.

- **Buzzer & Button**
  Simple experiment, press the button and both buzzers play the sound for 2 seconds.
- **IR Sensor & Servo w/ Serial Monitoring**
  When the sensor is triggered, the servo rotates and when it is not triggered the servo returns to its original position. Every 500ms the sensors status and the servos current rotation is shown through the serial monitor.
